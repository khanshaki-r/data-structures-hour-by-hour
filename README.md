# Data Structures, Hour by Hour

A plain-language study companion to Robert Lafore's *Sams Teach Yourself Data Structures and Algorithms in 24 Hours* (Sams, 1999).

**Read it online:** https://khanshaki-r.github.io/data-structures-hour-by-hour/

## What's inside

- All 24 hours, plus the Introduction and appendixes, in the book's order
- 97 C++ listings that keep the book's class and function names
- 187 diagrams of arrays, lists, stacks, queues, trees and hash tables
- 29 interactive Workshop applets that re-create the book's Java applets in JavaScript
- A summary, Q&A and quiz (with answers) at the end of every hour

## About this project

This is an independent companion, not a copy of the book. It follows the book's published table of contents and retells its examples in original wording, with freshly written code. The whole site is a single `index.html` file, so you can also download it and open it locally.

It is not affiliated with Sams Publishing or Robert Lafore.
